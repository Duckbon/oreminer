How a run goes

Every system plays the same four beats, and each lap is faster than the last.

  1. Tap the asteroid

    Each tap mines ore. Keep tapping inside 0.9 seconds and a combo builds, up to double ore per tap.

  2. Automate it

    Spend ore on drones and refineries that mine every second, including while the app is closed.

  3. Launch

    Hit the system's ore target and warp to the next star. Ore and upgrades reset. Warp Cores and a new upgrade come with you.

  4. Rebirth

    Clear all ten systems and start again at Sol Belt with +10% production for good, plus a Skill Point to spend.

Ten systems, one route

Each system has its own colour, a bigger ore target and a new upgrade. Pick a stop to see what's there. The whole page changes colour with it, the way the game does when you land.

    The daily spin

    After each daily reward you spin for a 1-in-3 shot at the asteroid shooter mini-game.

    A skill tree that lasts

    Rebirths earn Skill Points. Each perk has five levels and survives every reset.

    • Golden Touch +4% ore per tap
    • Auto Collector +4% ore per second
    • Efficient Drones +10% offline rate
    • Deep Pockets +2 hr offline time
    • Bargain Hunter -3% upgrade cost

    Three-minute challenges

    Three are always running: earn ore, tap a set number of times, or buy upgrades. Finish one in time and claim bonus ore.

    Ten achievements

    Each one adds 1% to everything you mine. Unlock all ten for a pile of ore and an extra Skill Point.
